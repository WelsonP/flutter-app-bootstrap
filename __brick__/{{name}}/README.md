# {{name}}

A production-ready Flutter app generated by [flutter_app_builder](https://github.com).

## Getting Started

### Prerequisites

- Flutter SDK >= 3.24.0
- Dart SDK >= 3.4.0
- A Supabase project (for auth)

### Setup

1. **Generate the app** (if not already done):
   ```bash
   mason make flutter_app_builder --name {{name}} --bundle-id {{bundle_id}} --supabase-url your-url --supabase-anon-key your-key
   ```

2. **Create platform directories** (if not present):
   ```bash
   flutter create --project-name {{name}} --org $(echo {{bundle_id}} | cut -d. -f1-2) .
   ```

3. **Set environment variables**:
   ```bash
   flutter run --dart-define=SUPABASE_URL={{supabase_url}} --dart-define=SUPABASE_ANON_KEY={{supabase_anon_key}}
   ```

4. **Run code generation**:
   ```bash
   ./scripts/generate.sh
   ```

5. **Run the app**:
   ```bash
   flutter run --dart-define=SUPABASE_URL=your-url --dart-define=SUPABASE_ANON_KEY=your-key
   ```
